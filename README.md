# Camigo Web

Camigo（校速达）校园智能快递系统前端。Phase 6 采用 Vue 3、Vite、TypeScript、Vue Router、Pinia、Element Plus、Axios 与 ECharts。

## 本地开发

```bash
npm install
npm run dev
```

后端默认运行于 `http://localhost:8080`，前端默认运行于 `http://127.0.0.1:5173`。可复制 `.env.example` 为 `.env.local` 调整 API 地址。

## 校验

```bash
npm run type-check
npm run build
```
