# Camigo 阶段8：管理员生成包裹设计

## 1. 依据与范围

本阶段仅依据《修改意见_最终执行版》第11节、第12.3节和阶段8要求实现。管理员可生成单件或最多10件联调包裹；不提供直接写库或跳过状态机的入口。本阶段不清理数据库，也不新增或删除表结构。

## 2. 接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/admin/parcel-generation/options` | 返回有效学生、可取件服务站、非服务站配送目的地、尺寸字典和批量上限 |
| POST | `/api/admin/parcel-generation` | 在一个事务中生成一批包裹并启动智能派单 |

两个接口均要求 `ADMIN` 角色。生成请求包含收件学生、取件服务站、配送目的地、尺寸、重量、可选到站时间和数量。

## 3. 领域事务

每个批次由 `AdminParcelGenerationService.generate` 的单一事务控制：

```text
校验批次共享选项
→ 选择目的地在线且尺寸兼容的目标柜
→ 创建 REGISTERED 包裹
→ 通过 ParcelLifecycleService 写 REGISTERED 初始日志
→ 通过 ParcelLifecycleService 转入 WAITING_ASSIGNMENT
→ 创建 CREATED 配送单并写入取件站和目的地
→ 调用 IntelligentDispatchService 启动第1轮智能派单
```

任一包裹、日志、配送单或派单步骤失败时，整批事务回滚。旧的管理员手工登记接口保留兼容，但管理端“生成包裹”页面只调用本阶段正式接口。

## 4. 校验规则

- 收件人必须是状态为 `ACTIVE` 且拥有有效 `USER` 角色的学生。
- 取件点必须有效且 `pickup_enabled = 1`。
- 目的地必须有效、`delivery_enabled = 1` 且 `pickup_enabled = 0`，因此服务站不能成为目的地。
- 目的地必须存在 `ONLINE` 快递柜，且至少具有不小于包裹尺寸的格口类型。
- 尺寸只能为 `S/M/L/XL`，重量范围为 `0.001–99999.999 kg`。
- 到站时间不得晚于当前时间，单批数量为 `1–10`。

## 5. 随机字段

`ParcelRandomDataGenerator` 只生成不影响业务选择的字段：承运商来自 `SF/YT/ZTO/JD/STO`；寄件人来自有限姓名字典；运单号由承运商、毫秒时间和随机数字组成；寄件人电话固定为中间四位脱敏格式。运单号发生唯一键冲突时有限次数重试，连续失败则整批回滚。

## 6. 管理端页面

路由 `/admin/parcels/generate` 提供完整表单、加载与空状态、服务端错误提示、防重复提交和逐件结果。页面只提交业务选择字段，随机字段和所有状态变更均由后端完成。

## 7. 验收覆盖

- 随机字典与格式单元测试。
- 选项接口、合法生成请求和非法批量参数控制器测试。
- 真实 MySQL 事务测试生成2件包裹，验证每件包裹恰有 `REGISTERED`、`WAITING_ASSIGNMENT` 两条日志，且收件人、取件站、目的地、目标柜、配送单和第1轮派单完整。
- 服务站目的地拒绝测试，并确认拒绝前后包裹数量不变。
- 集成测试使用 Spring 事务回滚，不污染现有数据。
